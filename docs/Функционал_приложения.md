# ПЕРЕЧЕНЬ ФУНКЦИОНАЛА ПРИЛОЖЕНИЯ ЯОКО
## (Приложение к договору / Акт выполненных работ)

---

## 1. ОБЩИЕ СВЕДЕНИЯ

**Наименование приложения:** Платформа локальных акций ЯОКО (YOKO)  
**Тип приложения:** Веб-приложение (SaaS)  
**Домен:** yaoko.ru  
**Архитектура:** Клиент-серверная (React + Express + PostgreSQL)

---

## 2. МОДУЛИ И ФУНКЦИОНАЛ

### 2.1. Модуль администрирования (Админ-панель)

#### 2.1.1. Управление организациями (партнёрами)
- Создание организации с автоматическим созданием аккаунта партнёра
- Редактирование данных организации (название, адрес, телефон, email, логотип)
- Просмотр карточки организации с полной информацией
- Удаление организаций
- Привязка партнёра к организации (email + пароль)
- Отображение пароля партнёра (с возможностью показа/скрытия)
- Генерация нового пароля партнёра

#### 2.1.2. Управление акциями
- Создание акций с параметрами:
  - Название, описание, эмодзи
  - Дата начала и окончания
  - Временные окна проведения (time_from, time_to)
  - Градиент фона для визуализации
  - Статус (активна/неактивна)
- Редактирование существующих акций
- Удаление акций
- Настройка видимости акций для других организаций (allowed_org_ids)
- Просмотр статистики по акции (количество выданных купонов)

#### 2.1.3. Управление точками
- Создание точек обслуживания
- Привязка точек к организациям
- Редактирование данных точек (название, адрес, статус)
- Активация/деактивация точек
- Удаление точек

#### 2.1.4. Управление планшетами
- Регистрация планшетов для розыгрыша
- Привязка планшетов к точкам
- Генерация логина/пароля для планшетов
- Отслеживание статуса планшетов (онлайн/офлайн, last_seen)
- Удаление планшетов

#### 2.1.5. Управление купонами
- Просмотр всех выданных купонов
- Фильтрация по статусу (issued/redeemed/expired)
- Отображение источника купона (точка, где выигран)
- Информация о владельце купона (имя, телефон)
- Данные акции, по которой выдан купон
- Срок действия купона

#### 2.1.6. Управление лидами
- Просмотр всех лидов (участников, выигравших купоны)
- Отображение источника лида (точка, акция)
- Контактные данные (имя, телефон)
- Статус лида
- Экспорт в CSV

#### 2.1.7. Управление участниками
- Просмотр базы участников (все, кто участвовал в розыгрышах)
- Статистика по участнику (количество участий, побед)
- Отображение источника (точка, где впервые зарегистрировался)
- Фильтры по статусу
- Экспорт в CSV

#### 2.1.8. Мониторинг и аналитика
- Дашборд с ключевыми метриками:
  - Количество организаций
  - Количество точек
  - Количество планшетов
  - Количество выданных купонов
  - Конверсия (выданные/погашенные)
- Периоды анализа (день/неделя/месяц)
- Графики и статистика

#### 2.1.9. Уведомления
- Системные уведомления в личном кабинете админа
- Email-уведомления о новых выигрышах
- Telegram-уведомления (опционально)

#### 2.1.10. Настройки
- Управление параметрами системы
- Настройка SMTP для отправки email
- Управление сессиями пользователей

---

### 2.2. Модуль партнёра (Личный кабинет партнёра)

#### 2.2.1. Обзор (Dashboard)
- Статистика по организации партнёра:
  - Количество акций
  - Количество лидов
  - Количество купонов
  - Конверсия

#### 2.2.2. Управление акциями
- Просмотр своих акций
- Создание новых акций
- Редактирование акций
- Удаление акций
- Статистика по каждой акции

#### 2.2.3. Управление лидами
- Просмотр лидов своей организации
- Контактные данные лидов
- Источники лидов (точки, акции)
- Фильтрация и поиск

#### 2.2.4. Управление купонами
- Просмотр купонов своей организации
- Статусы купонов (issued/redeemed/expired)
- Информация о владельцах купонов

#### 2.2.5. Погашение купонов
- Ручное погашение по коду купона
- Список всех купонов для погашения
- Отображение информации о купоне:
  - Имя владельца
  - Телефон
  - Акция
  - Дата выигрыша
  - Статус (погашен/не погашен)
- Кнопка «Погасить» для каждого купона

#### 2.2.6. Уведомления
- Системные уведомления в личном кабинете
- Email-уведомления о новых выигрышах

#### 2.2.7. Настройки
- Просмотр данных организации
- Смена пароля

---

### 2.3. Модуль планшета (Клиентский сценарий)

#### 2.3.1. Авторизация планшета
- Вход по логину/паролю планшета
- Сохранение сессии в sessionStorage
- Выход из планшета

#### 2.3.2. Приветственный экран
- Отображение информации о точке
- Кнопка начала розыгрыша

#### 2.3.3. Регистрация участника
- Ввод имени участника
- Ввод номера телефона с форматированием:
  - Формат: +7 (xxx) xxx xx xx
  - Ограничение: 10 цифр после +7
  - Корректная работа курсора при редактировании
  - Защита префикса +7 от удаления
- Проверка существующего участника по телефону
- Автоматический поиск в базе

#### 2.3.4. Согласие на обработку персональных данных
- Отображение текста согласия
- Чекбокс согласия
- Подтверждение участия

#### 2.3.5. Розыгрыш приза (Слот-машина)
- Анимированный барабан с акциями
- Плавная анимация вращения (GSAP)
- Серверный розыгрыш (честная лотерея)
- Исключение собственной организации из розыгрыша
- Учёт временных окон акций
- Отображение выигрышной акции

#### 2.3.6. Экран купона
- Отображение выигранного купона:
  - Название организации (акции)
  - Название акции
  - Эмодзи акции
  - Код купона (уникальный, с префиксом точки)
  - Срок действия купона (обратный отсчёт)
  - Адрес организации
  - Описание акции
- Анимация купона (shimmer-эффект)
- Визуальные эффекты (градиенты, свечение)

---

### 2.4. Модуль авторизации и безопасности

#### 2.4.1. Аутентификация
- Вход по email/паролю (админ, партнёр)
- Вход по логину/паролю (планшет)
- Сессии на основе PostgreSQL (connect-pg-simple)
- Скользящий срок сессии (продление при активности)
- Настройка срока жизни сессии (по умолчанию 12 часов)

#### 2.4.2. Безопасность
- Хеширование паролей (bcrypt, 12 раундов)
- Защита от CSRF (sameSite cookies)
- HttpOnly cookies
- Secure cookies для HTTPS
- CORS с настройкой разрешённых доменов
- Ролевая модель доступа (admin/partner/tablet)

#### 2.4.3. Управление паролями
- Смена пароля
- Отображение пароля (иконка «глаз») во всех формах
- Генерация пароля при создании партнёра
- Хранение пароля в открытом виде для отображения админу (password_plain)
